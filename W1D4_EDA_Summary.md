# W1D4 — Exploratory Data Analysis (EDA) Summary

## Objective

The aim of this task was to explore the dataset and understand its structure, data quality, intent distribution, and confidence-score distribution.

## Dataset Overview

The dataset was loaded using Pandas and examined using basic descriptive statistics.

The analysis included:
- Dataset shape and preview
- Data types
- Missing-value checks
- Duplicate-row checks
- Descriptive statistics
- Intent frequency analysis
- Confidence-score distribution

## Visualizations

The following visualizations were created:
- Distribution of confidence scores
- Distribution of intents
- Average confidence by intent
- Box plot of confidence scores

## Key Findings

The exploratory analysis helped identify the distribution of intents and confidence scores in the dataset. It also confirmed the presence or absence of missing values and duplicate rows.

The average confidence for each intent was calculated to compare confidence levels across different intent categories.

## Conclusion

EDA provided an initial understanding of the dataset and helped identify important patterns and data-quality characteristics that can be useful for subsequent machine-learning tasks.
